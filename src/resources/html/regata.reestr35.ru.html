Сценарий проекта:

  • формирование команд (цель выявить лидеров и позволить им сформировать команды по своему усмотрению);
  • обозначение условий, времени и критериев оценки работы команд по заданным критериям;
  • работа над создание картины по трем этапам (эскиз - колорирование - детализация) с подробным анализом ошибок на каждом этапе и адаптацией выводов в бизнес-среду; 
  • акцентирование в процессе работы на ресурсы команд и способы повышения эффективности их деятельности;
  • формулирование выводов по результатам игры для повышения деятельности рабочих команд компаний. 

Подобный сценарий позволит внедрить новую уникальную форму работы, в результате которой максимально эффективно сочетается креативная творческая составляющая (позволяющая участникам почувствовать себя творцами) и бизнес-обучение для работы в новых условиях или в новой деятельности. А главное, сильнейший мотивирующий эффект для реализации игры в работу.
